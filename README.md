# Sala Dobradiça Digital

Projeto experimental em A-Frame com navegação por teclado no desktop e joysticks virtuais no mobile.

## Controles

### Desktop

- Mouse: clicar, arrastar e soltar para olhar
- WASD ou setas: movimentação

### Mobile

- Joystick esquerdo: movimentação
- Joystick direito: controle do olhar

## Estrutura do projeto

- `index.html`: arquivo principal da cena
- `js/aframe.min.js`: biblioteca A-Frame local
- `models/caixa.glb`: modelo principal
- `models/aranha.glb`: modelo complementar

## Observações

A cena usa materiais convertidos para aparência plana, sem sombras dinâmicas, e joysticks virtuais para navegação em dispositivos móveis.
